# Mycelview 갱신 기획안 및 구현 현황

기준일: 2026-11-10. 이 문서는 최초 기획 이후 사용자가 요청한 변경사항을 우선 적용한 현재 기준이다. 초기 설계의 자유 배치·독립 파일 카드는 현행 기본 화면 요구에서 제외한다.

## 1. 제품 정의

**Mycelview (마이셀뷰)** — **Your Files, Your Workspace.**

내 파일과 폴더를 한눈에, 한곳에서. Windows의 여러 폴더를 카드로 펼쳐 보고 파일 즐겨찾기와 검색을 함께 사용하는 개인 파일 작업공간이다. 경로와 메모는 로컬에 저장하며, 등록이나 표시 순서 변경으로 원본 파일을 이동하지 않는다.

대상은 Windows 10/11, C#/.NET 10/WPF/MVVM이다. 사용자 설정은 JSON, 검색 인덱스는 SQLite에 저장한다. Windows Shell API로 실행과 파일 형식 아이콘을 처리한다.

## 2. 최종 화면 구조

| 영역 | 현재 기준 |
|---|---|
| 상단 브랜드 | 사용자가 제공한 창 모양 로고, 굵은 Mycelview, 영어/한국어 슬로건. 스킨별 기존 강조색 유지 |
| 상단 검색 | 입력 즉시 PC 로컬 인덱스 검색. 검색/취소 버튼 없이 입력창 오른쪽 × 버튼만 제공 |
| 검색 결과 | 입력창 아래 오버레이 팝업으로 표시하며 아래 작업공간을 밀어내지 않는다. 선택·다중 선택·드래그 등록, 아이콘·이름·경로·수정한 날짜·크기·유형 표시 |
| 왼쪽 | 통합 파일 탐색기. 드라이브/폴더 트리, 경로 입력, 현재 폴더 파일 목록 |
| 가운데 | 폴더 카드 2열 자동 배치, 카드 수 증가 시 다음 행으로 배치 |
| 오른쪽 위 | 파일 즐겨찾기 1열 목록. 독립 파일 카드 방식은 사용하지 않음 |
| 오른쪽 아래 | Mycelview에서 최근 연 파일, 최신순 100개 |

각 목록과 카드 내부는 독립 스크롤한다. 탐색기 폭, 오른쪽 폭, 탐색기 트리 높이, 즐겨찾기/최근 파일 높이 비율은 조절 후 저장하고 다음 실행에 복원한다. 창이 작아진 경우 조작 가능한 최소 크기로 보정한다.

## 3. 등록과 정렬

- 탐색기 또는 검색 결과에서 폴더/파일을 선택하여 일괄 등록할 수 있다.
- 선택 항목을 가운데/오른쪽 영역으로 드래그해도 등록한다. 폴더는 폴더 카드, 파일은 파일 즐겨찾기로 분류한다.
- 카드와 즐겨찾기 이름 앞의 ⠿ 핸들로 각각의 표시 순서를 바꾼다. 드래그 중 포인터를 따라오는 미리보기를 표시하고 주변 항목은 약 180ms 애니메이션으로 이동한다. 원래 배치 위치로 대상을 판정하며, 드래그 중 실제 컬렉션은 변경하지 않고 놓을 때 한 번만 순서를 바꾼다. 놓으면 저장하고 Esc 또는 영역 밖 드롭은 원래 순서로 복원한다. Windows 애니메이션 끄기 설정을 따른다.
- 폴더의 왼쪽/오른쪽 절반 또는 파일 행의 위쪽/아래쪽 절반을 기준으로 앞/뒤 삽입 위치를 표시한다.
- 순서를 바꿔도 폴더 2열/파일 1열 자동 배치는 유지하고, 변경 순서는 재실행 후 복원한다.
- 같은 원본 파일을 여러 번 등록할 수 있으며 각 항목은 고유 ID와 독립 메모를 가진다.
- 폴더와 파일 영역 간 순서 이동은 허용하지 않는다. 새 항목 등록과 기존 항목 순서 변경의 드래그 데이터를 구분한다.

## 4. 폴더 카드

### 탐색과 표시

최초 등록 폴더명을 제목으로 유지하고 현재 경로를 작은 글씨로 표시한다. 뒤로/앞으로/상위/원래 위치/새로고침을 제공한다. 하위 폴더 더블클릭은 카드 안에서 탐색하고 파일 더블클릭/Enter는 기본 연결 프로그램으로 실행한다.

새 카드는 펼쳐 등록한다. 개별 및 전체 접기/펼치기, 메모 표시/숨기기, 복제, 등록 해제, 경로 복사, Windows에서 열기, 누락 경로 재연결을 제공한다. 등록 해제는 원본 삭제가 아니다.

### 공통 크기

펼친 폴더 카드는 모두 동일 높이를 사용한다. 폴더 즐겨찾기 제목 옆의 −/＋ 버튼으로 260~800 DIP에서 20 DIP씩 전체 높이를 조절한다. 표시할 정보 메뉴도 제목 옆에 둔다. 폭은 2열 영역에 맞춰 동일하게 계산한다. 접힌 카드는 간결한 높이를 사용하며 펼치면 공통 높이로 복원한다. 이전 자유 배치 좌표/개별 폭은 저장 호환성용으로 남지만 현행 화면에서 사용하지 않는다.

### 열 구성

| 열 | 기본 상태 | 정책 |
|---|---|---|
| 이름 | 표시 | 숨길 수 없음, 파일 형식 아이콘 포함 |
| 수정한 날짜 | 표시 | 숨김 가능. 기존 ‘수정일자’ 명칭 변경 |
| 크기 | 표시 | 숨김 가능, 오른쪽 정렬 |
| 유형 | 숨김 | 선택 추가, Windows Shell 형식 이름 |
| 만든 날짜 | 숨김 | 선택 추가 |
| 확장명 | 숨김 | 선택 추가 |

현재 열 선택은 폴더 카드 전체에 공통 적용한다. 정렬·스크롤 상태를 저장한다. 임의의 모든 Windows Shell 속성 선택은 아직 지원하지 않는다.

## 5. 파일 즐겨찾기와 최근 연 파일

파일 즐겨찾기는 작은 글씨의 1열 목록으로 표시한다. 이름 약 11 DIP, 경로 약 9 DIP이며 긴 경로는 줄임표/툴팁으로 확인한다. 파일 실행, 메모 편집, 경로 복사, 재연결, 등록 해제와 표시 순서 변경을 지원한다.

최근 연 파일은 Mycelview에서 성공적으로 Windows 파일 열기를 요청한 파일만 기록한다. 동일 경로는 중복 없이 맨 위로 갱신하고 최근 100개를 저장한다. 다시 열기와 즐겨찾기 추가/드래그 등록을 제공한다. Windows 전체 사용 기록 수집이나 연결 프로그램 내 문서 로딩 성공 감지는 포함하지 않는다.

## 6. 스킨과 아이콘

Windows 11 Fluent Light를 기본으로 사용하며, 사용자 제공 Vercel 스타일은 선택 가능한 모노크롬 스킨으로 제공한다. 스킨은 즉시 적용하고 선택을 저장한다. 브러시·폰트·모서리·컨트롤 스타일을 분리하여 추가 스킨을 쉽게 등록할 수 있도록 한다.

파일 아이콘은 스킨과 독립적이다. 탐색기, 폴더 목록, 검색 결과, 즐겨찾기, 최근 목록에서 Windows에 등록된 HWP/XLSX/PDF 등 파일 형식 아이콘의 원래 색상을 유지한다. 미등록 형식은 Windows 기본 아이콘을 사용한다. EXE별 커스텀 아이콘/바로가기 대상 아이콘 추적은 별도 확장이다.

## 7. 통합 검색 — 현재 기준

### 조작

- 글자를 입력하면 약 60ms의 짧은 입력 대기 후 자동 검색한다. 검색 버튼/취소 버튼은 두지 않는다.
- × 버튼은 검색어와 결과를 지우고 진행 중인 조회를 취소한다.
- 검색창/검색 결과 바깥을 클릭하면 목록만 접는다. 검색어와 결과는 유지한다.
- 검색창을 다시 클릭하거나 입력하면 결과 목록이 다시 나타난다.
- 최초 200개를 우선 표시하고 ‘결과 더 보기’로 200개씩 추가한다. 표시 건수와 추가 결과 존재 여부를 구분하며 전체 결과 개수로 오인시키지 않는다.
- 결과 조회는 작업 스레드에서 수행하고 이전 입력의 조회는 취소한다. 오래된 결과가 최신 검색에 섞이지 않게 한다.

### 문법

| 입력 | 의미 |
|---|---|
| `예산` | 파일명/전체 경로에 예산 포함 |
| `예산 2027` | 공백을 AND로 처리 |
| `예산 AND 2027` / `예산 & 2027` | AND |
| `예산 OR 결산` | OR |
| `예산 AND NOT 초안` / `예산 & !초안` | 제외 |
| `(예산 OR 결산) & 2027 & !초안` | 복합 조건 |
| `"2027년 예산"` | 연속 문자열 |
| `ㄱ` / `ㄱㅅ` | 한글 초성 포함 검색 |

우선순위는 괄호 → NOT → AND → OR이며 연산자 대소문자를 구분하지 않는다. 중첩 괄호와 잘못된 검색식 안내를 제공한다. 파일 본문은 검색하지 않는다.

### 지속 인덱스와 변경 감지

- 최초 실행 시 접근 가능한 로컬 드라이브의 파일명·경로·종류·크기·날짜·초성 검색 키를 SQLite에 수집한다.
- 인덱스는 `%LocalAppData%\PinShelf\search-index.sqlite`에 유지한다. WAL 트랜잭션으로 일부 수집이 완료된 동안에도 조회할 수 있다.
- 실행 중에는 FileSystemWatcher로 생성·변경·삭제·이름변경을 감지하고 해당 항목/새 하위 폴더만 갱신한다.
- 재실행 시 저장된 인덱스를 즉시 재사용하면서 종료 중 누락된 변경을 메타데이터 재확인으로 보완한다. 이때 드라이브를 다시 읽지만 실제 DB 행은 변경된 경우만 갱신한다. 매번 인덱스를 지우고 재구축하지 않는다.
- 감시 누락/버퍼 초과 또는 새로 감시가 가능해진 드라이브는 재확인한다. 감시 등록 실패는 재시도한다.
- 인덱싱 여부, 확인한 항목 수, 변경 반영 수, 남은 폴더와 오류 상태를 표시한다. 전체 개수를 사전에 알 수 없어 가짜 백분율은 표시하지 않는다.
- 접근 불가 경로, 준비되지 않은 드라이브, 연결 폴더의 하위 내용은 미확인 범위로 표시한다. 실패한 디렉터리의 기존 항목은 임의로 삭제하지 않는다.
- 현재 Windows USN 저널 기반 변경 추적은 아니다. Everything과 같은 전 PC/모든 검색식 1초 미만 성능을 보장하지 않으며 104만 항목의 실측 조회는 약 14~59ms, 프로그램 방식 입력부터 결과 레이아웃까지 약 125~437ms였다. 시작 시 메모리 검색 캐시 준비는 약 6초, 측정 앱 작업 집합은 약 695MB였다.

## 8. 저장과 원본 보호

사용자 설정/메모/순서/경계/열/최근 파일은 `%LocalAppData%\PinShelf\workspace.json`에 저장한다. 임시 파일 후 교체와 직전 .bak 백업을 사용한다. 손상된 설정은 원본 보호를 위해 자동 덮어쓰지 않는다.

검색 인덱스에는 경로와 메타데이터만 저장하며 파일 본문이나 원본 복사본은 저장하지 않는다. 테스트는 개발 전용 폴더에서 진행한다. 현재 등록·순서 변경·검색·인덱싱으로 원본을 이동/복사/삭제하지 않는다.

## 9. 구현 상태

### 구현 및 자동 검증 완료

- 독립 Windows 창, .NET 10/WPF, 한국어 UI
- 통합 탐색기, 실제 폴더 트리/목록, 경로 탐색
- 폴더 2열 자동 배치, 파일 1열 즐겨찾기, 최근 파일 분할 영역
- 선택/다중 선택 및 드롭 데이터 등록 처리
- 독립 카드 탐색, 메모, 접기/복원, 재연결, 복제/등록 해제
- 폴더/파일 순서 변경 로직과 영속성
- 공통 카드 높이, 표시 열 설정, 정렬/스크롤 복원
- 스킨 선택, 로고/슬로건, 스킨 독립 Shell 파일 형식 아이콘
- 논리식·초성 검색, 입력 자동 조회, 제한된 초기 결과와 더 보기
- 검색어 지우기, 결과 접기/재표시 동작
- SQLite 저장/재사용, 생성·수정·이름변경·삭제·새 하위 폴더 증분 갱신
- 종료 중 변경 재확인, 최근 파일 및 영역 경계 재시작 복원

### 구현되어 있으나 추가 실사용 검증 필요

- 물리적 마우스로 드래그/드롭하는 전체 입력 경로와 경계 조절
- 실제 Windows 기본 연결 프로그램 실행 및 이에 따른 최근 기록
- 폴더/파일 선택 대화상자, Windows 10, 다른 DPI/다중 모니터
- 최초 인덱스 완주와 104만 항목 성능 측정 완료. 추가 규모·환경의 지연/메모리 스트레스 검증
- 대량 변경/감시 버퍼 초과, 연결 해제/재연결, 복잡한 권한 및 클라우드 경로

### 미구현 또는 후속 확장

1. 카드 간 원본 파일/폴더 이동·복사, Ctrl/Alt 드래그 구분, 충돌 처리, 안전한 실행 취소
2. A/B/C 호버 확대, 배율/고정 크기, 카드별 설정, 핀, 애니메이션 및 경계 보정
3. 여러 작업공간/업무별 탭 — 2026-11-10 구현 완료(최신 ROADMAP 참조)
4. 카드 전체 가상화, 대량 목록 점진 로딩/동시성 제한, 초대형 인덱스 최적화/USN 검토
5. 파일 미리보기, 문서 본문 검색, 네트워크 검색
6. 사용자 설정 백업/복원 UI, 인덱스 관리·복구 UI
7. 설치 패키지, self-contained 배포, 자동 업데이트

최신 미구현 범위와 추천 개발 순서는 ROADMAP.md를 기준으로 한다.

## 실제 파일 관리 (2026-11-10 추가)

- 우클릭으로 복사·잘라내기·붙여넣기, 이름 변경, 새 폴더, 휴지통 이동을 제공한다. 이름 변경은 선택한 항목의 새 이름을 표에서 각각 입력한다.
- 단축키: Ctrl+C/X/V, F2, Ctrl+Shift+N, Delete. 메모/주소 입력창에서는 원래 텍스트 편집 단축키를 유지한다. Shift+Delete 영구 삭제는 제공하지 않는다.
- 폴더 카드 내부/탐색기 빈 곳에서 붙여넣기와 새 폴더를 실행한다. 폴더 항목 자체의 메뉴는 그 폴더를 대상으로 한다. 메뉴 툴팁에 대상 경로를 표시한다.
- Windows FileDrop + Preferred DropEffect로 탐색기와 복사·잘라내기를 교환한다. 잘라내기는 붙여넣을 때만 원본을 이동한다. 실패·건너뜀·취소된 원본은 클립보드에 남기며, 사용자가 중간에 클립보드를 바꾸면 덮어쓰지 않는다.
- 같은 이름은 덮어쓰기(폴더는 병합), 건너뛰기, 다른 이름 보관, 전체 취소 중 선택한다. 같은 종류의 남은 충돌에 적용할 수 있다. 파일/폴더 상호 덮어쓰기는 막는다. 내부 항목 충돌 및 작업 직전 생긴 경합은 Windows Shell UI로 처리한다.
- 원본과 하위 항목을 함께 선택하면 상위 항목만 작업한다. 자기 자신/하위 폴더로 복사·이동, 드라이브 루트 대상 작업, 잘못된 새 이름을 차단한다.
- 실제 실행은 Windows IFileOperation을 별도 STA 스레드에서 수행한다. 진행률과 작업 취소는 Mycelview 하단과 Windows 진행 창에서 제공한다. 이미 완료된 항목은 유지하며, 취소를 전체 롤백으로 표시하지 않는다. Windows 대화상자가 열려 있으면 그 창에서도 취소할 수 있다.
- 휴지통 처리가 불가능하여 영구 삭제로 전환되는 요청은 진행 콜백에서 차단한다. 메뉴는 원본 휴지통 이동과 등록 해제를 구분한다.
- 이동/이름 변경이 성공하면 관련 카드·즐겨찾기·최근 기록의 경로를 갱신한다. 현재 탐색 목록도 다시 읽는다.
- Windows 실행 취소 기록은 요청하지만 Mycelview 자체의 Ctrl+Z/실행 취소 메뉴와 전체 작업 롤백은 아직 구현하지 않았다. 카드 간 일반 드래그는 이동, Ctrl 드래그는 복사하며 대상 카드의 현재 열린 폴더를 사용한다. 다중 선택과 기존 충돌/취소 처리를 공유한다.

## 폴더 카드 확대 보기 (2026-11-10)

- 확대 닫기 버튼, 같은 확대 버튼, Esc, 바깥 배경 클릭으로 닫는다. 작업공간 전환·카드 등록 해제·프로그램 종료 시에도 닫는다.

## 카드 상단 호버 자동 확대 (2026-11-10, 수동 확대 설계 갱신)
- 폴더명/경로와 버튼줄의 두 행으로 이루어진 CardHeader에 마우스를 올리고 지정한 시간 동안 머물면 자동 확대. 기본 A·150%·350ms.
- A: 원래 카드 위치에 떠오르며 주변 2열 슬롯 유지. 배경을 가리거나 입력을 막는 모달 창이 아니다.
- B: 해당 카드의 가로·세로 크기를 키워 같은 줄의 다른 카드와 아래 줄을 밀어낸다. 닫으면 원래 순서/2열 배치로 복원한다.
- C: 자동 및 버튼 확대 없음. 상단 ‘카드 확대 · A/B/C’ 버튼에서 설정한다.
- 크기는 110~300% 또는 고정 너비 400~2400/높이 260~1800 DIP. 실제 창/작업공간 범위에 맞춰 제한한다. 폰트 배율은 변경하지 않는다.
- 카드 안에서는 유지하고 카드 밖으로 나온 뒤 300ms 후 닫는다. 메모·컨텍스트 메뉴·파일 작업·마우스 캡처 중에는 닫기를 유예한다. Esc/확대 버튼으로 즉시 닫기, 드래그 중 자동 시작 방지. 버튼으로 직접 연 경우에는 직접 닫는다.
- 전역 설정으로 모든 업무 탭에 적용하며 workspace.json 저장, 설정 백업/복원에 포함. 확대 자체의 임시 상태는 저장하지 않는다.
- 핀·카드별 설정·호버 전환 애니메이션은 이번 범위에 포함하지 않는다.

## 호버 확대 보완 (2026-11-10)
- 진입 대기 및 450ms 재진입 금지 제거. 상단 MouseEnter/MouseMove로 진입을 다시 확인하며 UI 입력 큐에서 즉시 시작한다. 확대는 140ms 크기 애니메이션을 사용한다(Windows 애니메이션 끄기 설정 준수).

- B 확대는 같은 행에서 선택 카드 폭을 늘리고 이웃 카드 폭을 나눠 줄인다. 이웃은 아래 행으로 이동하지 않으며 행 높이만 늘어난다. 이웃의 최소 표시 공간 때문에 요청 너비가 제한될 수 있다.
- 크기 선택은 배율/고정 크기 라디오 버튼으로 구분. 고정 크기 선택 시 너비·높이 입력 활성화. 대기 시간 UI 제거; 기존 DelayMs 저장 필드는 호환용이며 실행에 사용하지 않는다.

## 파일 목록 선택·이름 편집 (2026-11-11)
- 선택 셀 배경과 글자색을 같은 테마 규칙으로 명시해 흐린 글자 표시 방지.
- 첫 클릭은 선택. 단일 선택된 이름에 시스템 더블클릭 간격 이후 다시 클릭하면 행 내부 이름 편집. 더블클릭/드래그는 편집 대기를 취소한다.
- Enter 또는 편집칸 밖 포커스 이동으로 확정, Esc 취소. 파일은 확장자를 제외한 이름 부분을 먼저 선택한다. 기존 파일 작업 파이프라인으로 충돌·실행 취소 처리.
- 백그라운드 검증 --test-inline-rename: 선택 글자색, 인라인 편집, Esc 취소, 실제 이름 변경 및 Undo 검증.


## 2026-11-11 탐색기와 미리보기 갱신
- 탐색기 영역은 업무 탭 왼쪽 빈 공간까지 위로 확장. 업무별 작업공간 제목은 탐색기와 가운데 영역의 경계에 맞춘다.
- 탐색기 상위 폴더/새로고침 오른쪽의 연한 파란 패널 아이콘으로 접기. 왼쪽 띠에 남은 반대 아이콘으로 펼치기. 이전 너비 및 탭별 접힘 상태 저장.
- PDF 미리보기는 연속 세로 스크롤을 기본으로 사용. 화면 중앙 페이지 번호, 이동 버튼, 너비 맞춤, 확대/축소 제공. 화면 주변만 렌더링하므로 문서 전체 비트맵을 메모리에 보관하지 않는다.
