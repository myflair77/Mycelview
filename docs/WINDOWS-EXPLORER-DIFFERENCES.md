# Windows 탐색기와 Mycelview의 차이 — 2026-11-13

코드 검사와 숨겨진 WPF 검사 기준이다. 실제 마우스/키보드로 Windows 탐색기를 조작해 대조한 결과는 아니다.

## 이번에 추가한 보기

아주 큰 아이콘 / 큰 아이콘 / 보통 아이콘 / 작은 아이콘 / 목록 / 자세히 / 타일을 폴더 카드에 추가했다. 목록은 위에서 아래로 채우고 가로로 스크롤하며, 아이콘과 타일은 가로로 채우고 세로로 스크롤한다. 카드별 보기 설정을 저장하고 일반/확대 카드에서 공유한다. 화면 밖 아이템은 생성하지 않는다.

## 우선 확인하면 좋은 차이

1. 외부 탐색기와의 드래그 복사·이동, 하위 폴더에 놓기: 사용자 기대와 실제 작업 대상이 다르다.
2. F5와 Alt 탐색 단축키: 자주 사용하는 기본 조작이다.
3. 숨김 항목·확장명 옵션: 같은 폴더를 열었을 때 목록이 다른 이유가 된다.
4. 이미지 썸네일과 아이콘 보기 인라인 이름 변경: 보기 모드가 같아도 사용감에 차이가 있다.

추가 요청에 따라 외부 드래그, 탐색/삭제 단축키, 숨김·확장명 옵션, 썸네일을 구현했다. 하위 폴더 드롭도 구현했다. 아이콘 모드 분류 및 인라인 이름 변경 등 나머지 차이는 유지된다.

## 검증 기록

- 7개 모드의 렌더링, 카드별 JSON 저장, 선택 유지, 실제 CardView 확대/축소 재배치를 검사했다.
- 5,000개 항목에서 생성된 항목 컨테이너는 보기별 7~50개였다. 화면 크기에 따라 달라진다.
- 큰 아이콘/목록/타일 렌더링 결과를 이미지 파일로 확인했다.
- 기존 Windows 메뉴 검사와 누락된 즐겨찾기 복구 메뉴 검사도 통과했다.
- 실제 마우스 조작은 하지 않았다. 컴퓨터 유즈 없이 숨겨진 테스트 창과 코드 검사를 사용했다.
