# Mycelview 개발 현황과 추천 순서

기준: 2026-11-10. 원래 기획안, 후속 사용자 변경 요청, 현재 소스와 검증 결과를 대조했다.

## 구현된 주요 기능

- Windows WPF 앱, Windows 11/Vercel 스킨, Shell 파일 형식 아이콘.
- 왼쪽 탐색기, 폴더 2열 카드, 파일 1열 즐겨찾기, 최근 연 파일.
- 독립 폴더 탐색, 메모, 접기/펼치기, 재연결, 공통 높이와 표시 열 설정.
- 드래그 순서 변경, 마우스 추적 미리보기, 자동 저장과 재실행 복원.
- 영속 SQLite 검색 인덱스, 변경 감지, 초성 및 AND/OR/NOT/괄호 검색, 입력 즉시 결과와 오버레이 팝업.
- 104만 항목 전체 인덱싱 완료 및 성능 측정 완료. 작업 스레드 조회 약 14~59ms, 프로그램 방식 입력~레이아웃 약 125~437ms. 모든 환경에서의 성능 보장은 아님.
- 우클릭: 열기, 파일 위치 열기, 종류별 카드/즐겨찾기 등록, 경로 복사, Windows 속성 호출, 등록 해제. 목록의 다중 선택 유지/일괄 작업. 폴더 트리와 카드 제목은 단일 대상. 경로는 줄 단위 복사, 속성은 선택 항목별 호출, 등록 해제는 원본 유지.

## 구현했으나 실사용 검증이 남은 부분

- 실제 OS 마우스 입력의 드래그/드롭/취소/스크롤 경계, 실제 우클릭과 Ctrl/Shift 다중 선택.
- Windows 파일 위치 선택, 속성 창, 연결 프로그램 실행, 파일 선택 대화상자 및 외부 드롭.
- Windows 10, 배율 125~200%, 다중 모니터, 긴 경로·권한 오류·클라우드 동기화 폴더.
- 대량 변경, FileSystemWatcher 버퍼 초과, 드라이브 연결 해제/재연결 시 검색 인덱스 복구.

원래 채팅의 대괄호 경로로 마우스 도구가 초기화되지 않는다. D:\Mycelview 복사본이 준비되어 있으나, 해당 경로를 사용하는 작업 세션에서 실제 입력 검증이 필요하다. 앱 내부 좌표 테스트를 실제 OS 입력 검증으로 간주하지 않는다.

파일 본문 검색과 네트워크 경로 검색은 현재 미구현인 후속 확장 후보이며, 위 기본 기능 안정화 후 범위를 결정한다. 새 폴더/이름 변경/휴지통 메뉴는 최근 제안에서 확장된 파일 관리 범위다.

## 후속 요청으로 대체된 원래 기획

자유 좌표 배치, 파일 독립 카드, 카드별 제각각 크기는 미완료 항목으로 잡지 않는다. 각각 폴더 2열 자동 배치, 파일 1열 목록, 공통 카드 높이로 변경됐다.

## 당장 진행할 묶음

실제 조작 QA → 원본 파일 관리 기반과 충돌 처리 → 백업·복구를 먼저 완료하는 것을 추천한다. 원본 변경 기능은 개발 전용 fixtures에서 실패 복구까지 검증한 뒤 사용자 업무 자료에 적용한다.

## 2026-11-10 최근 요청 완료

- 카드 첫 줄: 폴더명과 경로. 둘째 줄: 뒤로/앞으로/상위/새로고침/원래 위치/접기/메모/메뉴.
- 메모 호버 팝업, 클릭 편집과 자동 저장. 검색 결과 상태/범위는 작은 글씨 한 줄.
- 카드 사이 실제 다중 파일·폴더 이동/Ctrl 복사, 충돌 처리와 진행 취소. 대상 카드의 현재 경로 사용.
- 최종 검증: artifacts/tests-20261110-120323. 실제 마우스 입력은 도구 초기화의 대괄호 경로 오류로 미검증.

## 설정 백업·복원 구현 완료 (2026-11-10)

상단 설정 백업 메뉴에서 .pinshelf.json 내보내기/가져오기/자동 백업 복원 제공. 카드·즐겨찾기 순서, 경로, 메모, 공통 높이, 접힘, 표시 열, 정렬 기준/방향, 영역 분할, 스킨, 최근 기록 포함. 원본 파일과 검색 인덱스는 포함하지 않는다. 가져오기는 병합이 아닌 설정 교체이며 실행 중 즉시 적용한다. 현재 상태를 backups/before-restore-날짜-고유번호.pinshelf.json에 저장한 후에만 복원한다.

## 최신 완료

Ctrl+Z/메뉴/상단 실행 취소, 다중 작업·덮어쓰기·병합 복구, 이후 수정 보호. 로고 배경 제거와 밝은 파란색, 실제 앱 아이콘 포함. 디자인 선택 왼쪽 글자 ±1% 및 배율 영속 저장·백업 포함. 실행 취소 기록의 재시작 복원과 Ctrl+Y, 보관 파일 한도·기간 자동 정리는 구현 완료. 설치/업데이트 패키징은 후속 작업.


## 검색 인덱스 관리 구현 완료 (2026-11-10)
- 검색창 아래 상태 줄 오른쪽의 ‘인덱스 관리’에서 비모달 관리 창을 연다. 검색 가능한 항목 수, 누적 확인 수, 마지막 갱신, DB/WAL 용량을 표시한다.
- 전체 로컬 드라이브 또는 지정 폴더, 제외 폴더(하위 포함)를 설정하고 index-settings.json에 저장한다. 폴더 추가 대화상자와 줄 단위 직접 입력/삭제 지원.
- 변경 사항 재확인, 전체 재구축, 재구축 취소, 오류 경로 확인/선택 재시도/전체 재시도 지원. 오류는 최대 200개 표시.
- 재구축은 별도 세대 DB/메모리 캐시에서 수행하며 기존 검색/변경 감지는 계속된다. 완료 시 index-current.json을 원자적으로 교체하고 새 인덱스로 전환한다. 취소/실패 시 기존 인덱스를 유지하며 완료된 이전 세대 캐시는 진행 중 조회 종료 후 정리한다.
- 검색 범위 변경은 재구축 완료 시 적용한다. 저장 후 취소/종료한 설정은 다음 시작 시 다시 적용을 시도한다. 원래 설정 백업 파일에는 검색 설정/검색 DB를 포함하지 않는다.


## 업무별 탭과 접기/펼치기 전환 완료 (2026-11-10)
- 기존 평면 설정을 기본 작업공간으로 자동 이전. workspace.json 버전 2는 모든 작업공간과 마지막 활성 ID를 저장한다.
- 검색 아래 탭 표시. ＋ 작업공간, 이름 클릭 전환, ⋯/우클릭으로 이름 변경·복제·삭제. 왼쪽 점 핸들을 드래그하여 순서 변경.
- 탭별 카드/즐겨찾기와 메모, 정렬, 높이, 표시 열, 영역 분할, 스크롤 저장. 비활성 탭의 CardViewModel/감시기는 해제한다.
- 검색·인덱스, 최근 연 파일, 디자인·글자 배율, 실제 파일 작업 실행 취소/다시 실행 기록은 공통. 파일 이동/이름 변경/실행 취소는 비활성 탭의 연결 경로까지 갱신.
- 탭 복제는 설정만 복제하며 새 카드 ID를 부여한다. 탭 삭제는 원본 파일을 건드리지 않으며 전체 설정 사전 백업을 생성한다. 마지막 하나의 탭은 삭제 불가.
- 설정 내보내기/가져오기는 모든 탭을 포함하며 기존 단일 작업공간 백업도 지원한다.
- 폴더 즐겨찾기의 ‘모두 접기/모두 펼치기’는 한 버튼으로 교체. 매 클릭마다 동작이 번갈아 적용되고 다음 동작은 탭별로 저장된다.
- 별도로 요청된 로고 5종/10종은 채팅 비교용 시안으로만 생성. 제품 로고/ICO/브랜딩 자산은 변경하지 않음.


## 2026-11-10 폴더/카드 성능 최적화
- 카드/왼쪽 탐색기 목록은 공통 FolderListing을 통해 최대 2개까지 메타데이터를 읽는다. 128개부터 부분 결과를 표시하며 이후 배치는 크기를 늘리고 UI 처리 완료를 기다려 큐 폭증을 막는다.
- 목록 변경은 항목마다 알림을 보내지 않고 배치 교체한다. 동일 경로의 중복 새로고침을 합치고, 경로 전환/화면 이탈 시 이전 읽기를 취소한다.
- 2열 배치와 드래그 계산용 경량 슬롯은 유지하며 무거운 CardView/DataGrid/목록/감시기는 화면 주변에서만 유지한다. 편집 중이거나 메모 팝업을 연 카드는 유지한다. 다시 보일 때 최신 내용을 읽고 선택·스크롤·메모를 복원한다.
- 탭 전환 시 전체 폴더 읽기 완료를 기다리지 않고 조작 가능 상태로 돌아온다.
- 비교(격리된 12,000파일/61카드): 카드 준비 14,949.8→648.8ms, 생성된 CardView 61→6, 작업 집합 464.4→254.8MB. 모든 PC/폴더의 응답시간 보장은 아니며 초기 대량 렌더에서 측정된 최대 UI 간격은 약 602ms.

## 최신 UI 및 미리보기 완료 (2026-11-10)
- Space/우클릭으로 이미지·텍스트 미리보기, Esc 닫기, 선택 변경 시 갱신과 이전 로딩 취소. 텍스트 읽기 128KiB/표시 40,000자, 이미지 16MiB/100MP 제한과 최대 1600px 디코딩. 미지원 형식은 메타데이터 표시.
- ‘업무별 작업공간’, ‘＋ 새 업무 탭’, 선택 탭 배경 강조. 탭이 하나일 때 “업무1·업무2·업무3처럼 탭을 나눠 관리해 보세요.” 안내.
- 사용자 확정 로고(겹친 폴더와 앞쪽 왼편의 흰 문서)를 상단 벡터 및 앱 ICO에 적용. Assets/Logo.xaml을 공통 원본으로 generate-logo.ps1에서 16~256px 아이콘 생성. 상단은 스킨 강조색, 실행 파일 아이콘은 밝은 파란색.
- 다음 추천: 기존 2열 배치를 유지하는 폴더 카드 확대 보기(A 오버레이/C 끄기부터).

## 폴더 카드 확대 보기 (2026-11-10)
- 카드 버튼줄 ‘확대 보기’ 버튼으로 프로그램 창 내부 오버레이를 연다. 기존 2열 슬롯 크기와 저장된 높이/접힘 설정은 변경하지 않는다.
- 같은 CardView를 재사용하여 탐색·정렬·다중 선택·파일 작업·메모를 제공한다. 확대 중 카드 순서 드래그와 접기 버튼은 중지한다.
- 확대 닫기 버튼, 같은 확대 버튼, Esc, 바깥 배경 클릭으로 닫는다. 작업공간 전환·카드 등록 해제·프로그램 종료 시에도 닫는다.
- 최대 폭 1100 DIP, 창 가장자리 24 DIP 여백. 창 크기 변경 시 자동 조절하며 별도 팝업처럼 분리되지 않는다.
- 이번 범위는 수동 확대/닫기. 호버 자동 확대, 확대 배율·지연 설정, 고정 핀과 주변 카드를 밀어내는 확대는 후속 기능.

## 카드 상단 호버 자동 확대 (2026-11-10, 수동 확대 설계 갱신)
- 폴더명/경로와 버튼줄의 두 행으로 이루어진 CardHeader에 마우스를 올리고 지정한 시간 동안 머물면 자동 확대. 기본 A·150%·350ms.
- A: 원래 카드 위치에 떠오르며 주변 2열 슬롯 유지. 배경을 가리거나 입력을 막는 모달 창이 아니다.
- B: 해당 카드의 가로·세로 크기를 키워 같은 줄의 다른 카드와 아래 줄을 밀어낸다. 닫으면 원래 순서/2열 배치로 복원한다.
- C: 자동 및 버튼 확대 없음. 상단 ‘카드 확대 · A/B/C’ 버튼에서 설정한다.
- 크기는 110~300% 또는 고정 너비 400~2400/높이 260~1800 DIP. 실제 창/작업공간 범위에 맞춰 제한한다. 폰트 배율은 변경하지 않는다.
- 카드 안에서는 유지하고 카드 밖으로 나온 뒤 300ms 후 닫는다. 메모·컨텍스트 메뉴·파일 작업·마우스 캡처 중에는 닫기를 유예한다. Esc/확대 버튼으로 즉시 닫기, 드래그 중 자동 시작 방지. 버튼으로 직접 연 경우에는 직접 닫는다.
- 전역 설정으로 모든 업무 탭에 적용하며 workspace.json 저장, 설정 백업/복원에 포함. 확대 자체의 임시 상태는 저장하지 않는다.
- 핀·카드별 설정·호버 전환 애니메이션은 이번 범위에 포함하지 않는다.

## 폴더 카드 1~4열 (2026-11-10)
- ‘표시할 정보’ 바로 오른쪽에 ‘N열 자동 배치 ▾’ 버튼과 ‘⠿ 핸들로 순서 변경’을 같은 줄에 배치했다.
- 1열/2열(기본값)/3열/4열 선택. 열 수는 업무 탭별로 저장되며 탭 복제·설정 백업·재실행 복원에 포함된다.
- FolderGridPanel과 ReorderDragSession은 선택한 열 수를 사용한다. B 확대는 현재 줄을 확대 카드와 나머지 카드 줄로 나누고 아래 행을 밀어낸다. 닫으면 원래 열 수와 순서로 복원한다.

## PDF 본문 미리보기 (2026-11-11)
- Space/우클릭 미리보기에 Windows.Data.Pdf 기반 실제 페이지 렌더링 추가. 브라우저나 외부 PDF 프로그램 없이 앱에서 확인한다.
- 이전/다음, 페이지 번호 Enter, PageUp/PageDown, 25~400% 확대·축소와 맞춤. 확대 시 페이지를 다시 렌더링하며 최대 변 4096px로 제한한다.
- 현재 페이지 한 장을 렌더링하고 파싱한 PDF는 한 문서만 캐시한다. 파일 변경 시 재로드. 선택·페이지·배율 변경과 창 닫기에서 이전 작업 취소 및 오래된 결과 차단.
- 암호 입력 UI는 아직 없다. 암호 PDF·손상·읽기 실패는 오류와 원본 열기 안내. PDF 텍스트 선택/복사·검색·주석·편집은 이번 범위 아님.
- Windows SDK WinRT 참조를 위해 net10.0-windows10.0.19041.0으로 대상 지정. 기존 실행 경로 bin/Release/net10.0-windows 유지. NuGet은 공식 nuget.org 사용.
- 숨김 전용 검증: --test-pdf <결과폴더>. 실제 3페이지 PDF, 가로 페이지, 버튼 이동, 해상도 증가·제한, 취소, 빠른 전환, 손상 PDF, 파일 불변 및 화면을 띄우지 않는 WPF 캡처 검증.
- 후속 본문 미리보기 목표: docx, xls, xlsm, xlsx, pptx, md, html, xmind, drawio, hwp, hwpx. 현재 md/html은 원문 텍스트 표시이며 서식 렌더링은 후속.
- API 근거: https://learn.microsoft.com/en-us/uwp/api/windows.data.pdf.pdfpage.rendertostreamasync 및 https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/winrt-apis-desktop-apps
