# PinShelf · 핀셸프

**Your Files, Your Workspace.** 내 파일과 폴더를 한눈에, 한곳에서.

Windows 10/11용 .NET 10 WPF 파일 작업공간입니다. 실제 폴더를 카드로 등록하여 동시에 탐색하고, 폴더·파일 등록과 메모를 로컬에 보관합니다.

## 실행

이 개발 PC에서는 **`Run-PinShelf.cmd`를 더블클릭**합니다. 프로젝트 내부 `.tools/dotnet` SDK를 사용하므로 시스템 PATH 변경이 필요 없습니다.

다른 PC에서는 .NET 10 SDK(Windows x64)를 설치한 뒤 PowerShell에서 다음을 실행합니다.

```powershell
.\build.ps1
.\run.ps1
```

프로젝트의 `global.json`은 SDK 10.0.403 및 최신 패치를 사용합니다. 실행파일은 `src/PinShelf/bin/Release/net10.0-windows/PinShelf.exe`입니다. 시스템에 Desktop Runtime이 없고 프로젝트 전용 SDK만 있는 PC에서는 반드시 위 실행 스크립트를 사용하세요. 독립 배포 패키지와 설치 프로그램은 아직 없습니다.

## 현재 구현

- 디자인 스킨 선택: Windows 11 기본 / Vercel 모노크롬, 즉시 적용 및 선택 자동 저장 ([확장 안내](docs/SKINS.md))

- 실제 폴더 카드 여러 개 등록, 실제 이름·수정일자·크기 목록
- 왼쪽 통합 탐색기: 드라이브/폴더 트리 지연 로딩, 경로 입력, 상위 폴더, 새로고침, 실제 파일 목록
- Ctrl/Shift 다중 선택 후 등록 또는 작업공간으로 드래그하여 등록
- 파일 즐겨찾기는 오른쪽 1열 목록, 이름 11 DIP / 경로 9 DIP, 항목별 독립 메모
- 폴더 카드는 가운데 2열 자동 배치, 세 번째 폴더부터 다음 행에 배치
- 탐색기/폴더 즐겨찾기/파일 목록의 독립 스크롤과 영역 폭 조절
- 모든 파일 목록에 Windows Shell 파일 형식 아이콘 표시, 스킨과 무관하게 원래 색상 유지
- 카드별 뒤로/앞으로/상위/원래 위치/새로고침
- 폴더 더블클릭 탐색, 파일 더블클릭/Enter 및 즐겨찾기 열기
- 개별 및 전체 접기·펼치기, 이전 높이와 탐색 위치 보존
- 목록 정렬, 스크롤 위치 저장·복원
- 카드 메뉴: 메모, 전체 경로 복사, Windows에서 열기, 재연결, 복제, 등록 해제
- 외부 탐색기에서 파일·폴더를 작업공간으로 드롭하여 등록 (이동하지 않음)
- 비동기 파일 읽기, 목록 행 가상화, FileSystemWatcher, 45초 주기 재확인
- 650ms 지연 자동 저장, 종료 시 저장, 새 프로세스에서 복원
- 저장 시 원자적 파일 교체와 직전 파일 백업, 손상된 설정 감지 시 저장 중지
- 중복 실행 방지, DPI 인식, 기본 한국어 UI

카드 등록 해제는 원본을 삭제하지 않습니다. 이 버전에는 실제 파일 이동·복사·삭제 기능이 없습니다.

## 데이터

일반 실행의 저장 위치는 `%LocalAppData%\PinShelf\workspace.json`입니다. 메모와 경로만 저장하고 원본 파일은 복사하지 않습니다. `.bak` 파일은 직전 저장본입니다. 설정 읽기에 실패하면 원본을 덮어쓰지 않고 경고합니다. 앱을 종료한 뒤 원본을 별도로 보관하고 정상 백업을 복원할 수 있습니다.

## 검증

```powershell
.\build.ps1 -Test
```

외부 테스트 프레임워크 없이 실제 WPF 창과 개발 전용 파일로 통합 테스트합니다. `artifacts/tests-날짜-시각`에 결과, 화면 PNG, 설정과 fixtures를 저장합니다. 별도 프로세스를 다시 실행하여 영속성을 확인합니다. 일반 사용자 설정과 업무용 파일은 테스트에 사용하지 않습니다.

물리적인 마우스 입력, 실제 파일 연결 프로그램 실행, 외부 탐색기 드롭, 파일 선택 대화상자는 아직 수동 검증이 필요합니다. 테스트는 실제 선택 등록 버튼, 드롭 데이터 처리, 자동 배치 좌표, 폴더 트리 읽기와 아이콘을 검증하며 물리적 드래그 입력 테스트와 구분합니다.

## 현재 레이아웃 사용법

왼쪽 트리에서 폴더를 고르거나 경로 입력 후 Enter를 누릅니다. 폴더 내용에서 Ctrl/Shift로 여러 항목을 선택하고 ‘선택 항목 등록’을 누르세요. 선택 항목 또는 트리 폴더를 가운데/오른쪽으로 드래그해도 등록됩니다. 놓는 영역에 관계없이 폴더는 2열 카드, 파일은 1열 즐겨찾기로 자동 분류하며 원본을 이동하지 않습니다. 파일 메모는 각 항목의 ⋯ 메뉴에서 표시합니다. 기존 파일 카드도 항목과 메모를 보존하여 목록으로 표시합니다. 이전 자유 배치 좌표는 저장 호환성을 위해 보존하지만 화면 배치에는 사용하지 않습니다.


## 순서·카드 높이·표시 열

- 폴더 제목 왼쪽 또는 파일 즐겨찾기 이름 왼쪽의 **⠿** 핸들을 드래그합니다. 폴더는 대상 카드의 왼쪽/오른쪽 절반, 파일은 대상 행의 위쪽/아래쪽 절반에 놓아 앞/뒤에 삽입합니다. 삽입선과 하단 안내를 표시합니다.
- 폴더는 2열, 파일은 1열 자동 배치를 유지합니다. 다른 종류의 영역으로 순서를 이동할 수 없습니다. 원본 파일은 이동하지 않습니다.
- **카드 높이** 슬라이더로 펼친 폴더 카드의 공통 높이를 260~800 DIP로 변경합니다. 접힌 카드는 간결한 높이를 유지하고 펼치면 공통 높이로 돌아옵니다.
- **표시할 정보**에서 모든 폴더 카드의 열을 설정합니다. 이름은 필수, 수정한 날짜/크기는 기본 표시, 유형/만든 날짜/확장명은 선택 추가할 수 있습니다. 크기는 오른쪽 정렬합니다. 유형은 Windows Shell에 등록된 형식 이름을 사용합니다.
- 순서, 공통 높이, 열 표시 설정은 자동 저장하고 재실행 시 복원합니다. 기존 설정은 기본 3열 및 공통 높이 340 DIP로 열립니다.
- 로고는 사용자 제공 모양을 WPF 도형으로 구현해 DPI 확대에도 선명하게 표시합니다. PinShelf는 굵게 표시하고 영어/한국어 문구를 함께 표시하며 스킨별 강조색을 유지합니다.

## PC 통합 검색

상단 검색창에 입력하면 약 120ms 후 자동 검색합니다. 검색/취소 버튼은 없고 입력창 오른쪽 ×로 지웁니다. 접근 가능한 로컬 고정/이동식/광학/RAM 드라이브를 순회하여 파일명·폴더명·전체 경로를 검색합니다. 본문 검색과 네트워크 드라이브 검색은 포함하지 않습니다.

| 예시 | 의미 |
|---|---|
| `예산 2027` | 두 단어 모두 포함 (공백 AND) |
| `예산 AND 2027` 또는 `예산 & 2027` | AND |
| `예산 OR 결산` | OR |
| `예산 AND NOT 초안` 또는 `예산 & !초안` | 제외 |
| `(예산 OR 결산) & 2027 & !초안` | 괄호 조합 |
| `"2027년 예산"` | 연속 문자열 |

우선순위는 괄호 → NOT → AND → OR이며 연산자 대소문자를 구분하지 않습니다. AND/OR/NOT 자체를 검색하려면 따옴표로 감싸세요. 검색식 오류는 화면에 안내합니다.

검색 결과에서 Ctrl/Shift로 다중 선택 후 **선택 결과 등록**을 누르거나 카드/즐겨찾기 영역으로 드래그합니다. 폴더는 카드, 파일은 즐겨찾기로 등록하며 원본은 이동하지 않습니다. 더블클릭/Enter로 폴더를 왼쪽 탐색기에 열거나 파일을 실행합니다. **원본 위치 열기**는 항목이 있는 부모 폴더를 Windows 탐색기로 엽니다.

검색은 한 글자/초성(ㄱ·ㄱㅅ)부터 동작합니다. 최초 200개를 빠르게 표시하고 결과 더 보기로 추가합니다. 바깥 클릭은 결과 목록만 접고 검색창 클릭으로 다시 엽니다. ×는 검색어와 결과를 지웁니다. 접근 실패/제외 경로는 상세 목록으로 확인합니다(총 제외 건수와 최대 200개 경로 표시). 연결 폴더(reparse point)는 순환 방지를 위해 하위 탐색에서 제외하므로 일부 클라우드/링크 경로는 미검색 상태로 표시됩니다. 준비되지 않은 드라이브와 권한 없는 폴더는 건너뜁니다.

현재 검색은 로컬 SQLite 인덱스를 조회합니다. 최초 전체 수집 이후 실행 중 변경 이벤트만 반영하고, 재실행 시 저장된 인덱스를 재사용하면서 종료 중 누락된 변경을 메타데이터 재확인으로 보완합니다. 파일 본문이나 외부 서버로의 전송은 사용하지 않습니다.

## 최근 연 파일

오른쪽 위는 **파일 즐겨찾기**, 아래는 **최근 연 파일**입니다. 가운데 경계선을 끌어 두 영역의 높이를 조절할 수 있고 각각 독립 스크롤합니다.

PinShelf의 폴더 카드, 탐색기, 검색 결과, 즐겨찾기/최근 목록에서 Windows에 파일 열기를 성공적으로 요청한 파일을 최신순으로 기록합니다. 같은 경로는 맨 위로 갱신하고 최근 100개를 로컬에 저장합니다. Windows 전체 또는 다른 프로그램에서 연 파일을 수집하지 않습니다. 연결 프로그램에서 문서를 실제로 다 읽었는지는 감지하지 않습니다.

최근 항목을 더블클릭/Enter로 다시 열거나 **＋** 버튼/드래그로 즐겨찾기에 등록합니다. 사라진 파일을 다시 열지 못하면 상태 표시줄에 오류를 안내합니다.

## 갱신 기획안

현재 전체 명세와 구현/검증/미구현 구분은 [docs/SPEC.md](docs/SPEC.md)에 정리했습니다.

로컬 인덱스는 사용자 설정 폴더의 search-index.sqlite에 저장합니다. 인덱싱 상태와 수집/변경 건수를 검색창 아래에 표시합니다. 최초 수집 중에는 부분 결과이며 모든 검색에 1초 미만 응답을 보장하지 않습니다. 영역 구분선의 폭/높이 비율도 저장·복원합니다.



### 업무별 작업공간
검색창 아래에서 `＋ 작업공간`으로 업무별 탭을 추가합니다. 탭 이름을 눌러 전환하고 `⋯` 또는 우클릭으로 이름 변경·복제·삭제합니다. 탭 왼쪽 점 핸들을 드래그하면 순서가 저장됩니다. 기존 자료는 ‘기본 작업공간’에 유지됩니다.
각 탭의 카드/즐겨찾기/메모/정렬/높이/표시 열/영역 분할을 별도로 저장합니다. 검색·최근 연 파일·실제 파일 작업의 Ctrl+Z/Ctrl+Y는 공통입니다. 탭 삭제는 원본 파일을 삭제하지 않으며 설정을 먼저 자동 백업합니다. 설정 백업/복원에는 모든 탭이 포함됩니다.
폴더 즐겨찾기의 한 버튼은 ‘모두 접기 → 모두 펼치기’로 번갈아 동작하며, 다음 동작은 탭별로 유지됩니다.
